# EasyVideo 视频捕获

配合 easyVideo 桌面客户端使用的 Chromium 浏览器扩展。它会观察当前标签页的网络请求，捕获 HLS（`.m3u8`）以及 MP4、WebM、FLV、MKV、MOV、M4V 等视频地址，并在你点击“下载”时，把视频地址和请求头发送给本机运行的 easyVideo 客户端。

## 前置条件

- 已安装并启动 easyVideo 客户端。
- 使用 Chrome、Edge 或其他基于 Chromium 的浏览器。
- 知道 easyVideo 的本地监听端口，默认是 `27853`。

## 安装扩展（加载已解压的扩展程序）

### Chrome

1. 打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本扩展所在目录（`extension` 文件夹）。
5. 建议把“EasyVideo 视频捕获”固定到浏览器工具栏。

### Edge

1. 打开 `edge://extensions/`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本扩展所在目录（`extension` 文件夹）。

扩展没有附带图标文件，浏览器会显示默认扩展图标。

## 配对 easyVideo

1. 启动 easyVideo 客户端。
2. 打开 easyVideo 的 **设置 → 浏览器扩展**，复制其中显示的访问令牌。
3. 点击浏览器工具栏里的扩展图标，再点击右上角齿轮打开设置页。
4. 填写：
   - **端口**：默认 `27853`。
   - **访问令牌**：粘贴刚才复制的令牌。
5. 点击“测试连接”，确认显示连接成功后，点击“保存”。

只有在填写了访问令牌后，扩展才能发起下载。令牌只保存在本机浏览器的扩展存储中。

## 使用方法

1. 保持 easyVideo 客户端运行。
2. 在浏览器中打开视频页面，播放一会儿，让页面发出视频请求。
3. 点击扩展图标查看当前标签页捕获到的视频；必要时点击“刷新”。
4. 点击某条记录右侧的“下载”，扩展会把地址和请求头发送给 easyVideo。
5. 如果页面本身受 yt-dlp 支持，也可以点击“下载当前页面”，由 easyVideo 调用 yt-dlp 解析并下载。

说明：

- 捕获列表按标签页区分，切换页面后会自动清空；每个标签页最多保留 50 条。
- `.ts`、`.m4s`、`.m4a`、`.aac`、`.vtt` 等分片或字幕文件不会单独列出。
- HLS 记录的下载文件名默认使用 `.mp4` 扩展名，实际封装格式由 easyVideo 处理。
- 受 DRM 保护的视频无法通过本扩展下载。

## 默认端口与修改方式

扩展默认连接 `http://127.0.0.1:27853`。

如果 easyVideo 中修改了本地 API 端口，请在扩展设置页把“端口”改成相同数值并保存。端口和令牌必须与客户端一致，否则会提示无法连接或令牌无效。

## 常见问题

**提示“无法连接 easyVideo（请确认客户端已启动，端口 27853）”**

- 确认 easyVideo 客户端已经启动。
- 确认扩展设置中的端口与客户端监听端口一致。
- 检查本机防火墙或安全软件是否拦截了 `127.0.0.1` 上的本地连接。

**提示“令牌无效（请在扩展选项里重新粘贴）”**

- 回到 easyVideo 的 **设置 → 浏览器扩展**，重新复制令牌。
- 在扩展设置页清空旧令牌，粘贴新令牌并保存。

**列表一直为空**

- 先播放视频，再点击弹窗里的“刷新”。
- 有些页面通过 Service Worker 或加密方式加载媒体，可能无法被页面请求观察到。
- DRM 视频不会产生可下载的直链。

**点击下载后 easyVideo 没有任务**

- 打开 easyVideo 查看是否出现错误提示，并确认客户端版本支持浏览器扩展 API。
- 部分站点需要请求头（如 Referer、Cookie）才能下载；扩展会自动转发捕获到的相关请求头。
- 目标站点不支持时，可以尝试“下载当前页面”交给 yt-dlp。

## 权限说明

- `webRequest`：观察媒体请求及响应头。
- `storage`：保存端口、访问令牌和临时捕获列表。
- `tabs`：获取当前标签页标题、地址，并按标签页整理捕获结果。
- 主机权限：访问网页媒体地址，以及本机 `127.0.0.1` 上的 easyVideo API。

扩展不加载远程代码，也不会上传数据到除本机 easyVideo 客户端以外的地址。
